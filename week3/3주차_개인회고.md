# 3주차 주간회고

소프티어 첫날이 엊그제 같은데 어느새 3주차가 마무리되었다. 

학습에 온전히 집중할 수 있는 시기는 이번 주로 마지막이기 때문에, 어느 정도는 마음의 여유를 가지며, 고민도 많이 해보고 궁금한 것도 끝까지 파고들어보자는 마음가짐으로 임했다.

<br>

미션은 이번 주로 끝을 맞이했다. 

이번 주 미션은 게시물 작성 기능과 이미지 업로드 기능을 구현하는 것이었다.

그동안은 텍스트 위주의 정보만을 주고 받았기 때문에 String으로 요청 정보들을 읽고 있었다. 하지만 이미지 업로드 기능을 위해서는, 요청을 바이트 기반으로 처리해야 했다. 

바이트를 직접 다뤄볼 경험은 많이 없었기 때문에, 여러 자료를 참고하면서 시행착오를 겪어야했다. 프레임워크가 얼마나 많은 것을 알아서 처리해주고 있었는지 감사함을 느낄 수 있었고, 한편으로는 그동안 상당한 부분을 의존하고 있었다는 것도 실감할 수 있었다.

<br>

이번 주에는 추상화에 특히 집중하면서 리팩토링을 진행했다. 추상화에 대해서는 익히 공부해왔지만, 직접 깊은 고민을 해보면서 추상화의 이점도, 반대로 어려운 점도 느낄 수 있었다. 

가장 어려웠던 것은, 추상화를 하면서도 이해하기 쉽고 가독성이 좋은 코드를 작성하는 것이었다. 여러 번의 수정을 거치며 고민해봤지만, 아직 실력적으로 다듬어야 될 부분이 많다는 것을 느꼈다. 스스로에게 새로운 도전을 주면서 많이 배울 수 있었던 것 같다.

<br>

두 번째 코드 리뷰도 진행했다.

지난 주보다는 많이 익숙해졌지만, 코드 리뷰 자체보다도 다른 사람의 코드를 온전히 이해하는 것이 오히려 더 어려웠다. 저번 주보다 기능도 복잡해졌고 추상화 수준도 높아졌기 때문에, 여러 파일들을 오가면서 구조와 동작 방식을 이해해야 했다. 

하지만 그러면서 새로 알게 된 개념이나 방식들도 많이 있었고, 코드를 파악하는 능력도 한 단계 성장할 수 있었다. 이 때 배운 것들을 다시 내 코드에 반영해보면서 선순환을 만들어갈 수 있었다.

<br>

미션을 마무리하면서 버그 데이를 진행했다.

서로가 개발한 웹 서버를 직접 테스트하면서 버그를 찾는 활동을 했다. 개발 단계에서 내가 신경썼던 부분들을 중점적으로 테스트했다.

버그 데이를 진행하면서, 개발 단계에서 미처 고민하지 못했던 부분이 많이 있었다는 것을 깨달을 수 있었다. 단순 실수로 인한 예외는 물론, 악의적인 사용자들에 대해서도 충분히 고려해야 한다는 것을 배웠다. 어떤 방식의 공격이 있을 수 있는지도 미리 알아둬야겠다고 생각했다.

<br>

종합프로젝트에서는 와이어프레임을 논의하면서 최종적으로 기능을 구체화했다.

기획/디자인 분들이 고생해주신 덕분에 정말 좋은 결과물이 나온 것 같다. 거의 모든 부분에서 마음에 들었다. 다만 몇 가지 의문이 드는 점이나, 개발 측면에서 생각해 볼 수 있는 문제점에 대해 말씀드리면서 약간의 조율을 했다.

개발 팀원들끼리 개발 일정이나 도구, 컨벤션 등을 하나씩 정하면서, 종합프로젝트에 돌입한다는 것이 실감나기 시작했다. 기술 스택과 API를 조사하며, 구현 방식에 대해서도 대략적으로 구상해보기 시작했다. 그 과정에서 개발자들의 입장을 기획/디자인 분들이 쉽게 이해할 수 있도록 정리하고 전달해보는 활동도 할 수 있었다.

<br>

3주 동안 소프티어 과정에 임하면서 많이 익숙하고 편안해졌다고 생각했는데, 또 다시 새로운 챕터로 넘어간다고 생각하니 약간의 긴장감과 설렘이 함께 느껴진다. 처음 도전해보는 영역이 많아 막연한 불안감도 들지만, 성장의 즐거움에 집중하면서 마지막까지 모든 것을 쏟아붓고 싶다.
